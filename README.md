# For Harinee — 18 Years of Us ♡

A vintage scrapbook-style birthday website made with HTML, CSS and JavaScript.

## Preview
Open `index.html` in a browser, or use VS Code Live Server.

## Photos already added
Your uploaded photos have been placed in `assets/photos/`:
- `cover.jpg` — childhood tree photo for the opening
- `memory-1.jpg` — another tree photograph
- `memory-2.jpg` — indoor silly photo
- `memory-3.jpg` — photo collage
- `memory-4.jpg` — childhood tree photograph

Replace any of these files with another photo while keeping the same filename if you want to change the gallery.

## Personalize further
- Edit the birthday letter in `index.html`.
- Change the little memory card messages in the `data-message` attributes.
- Update the sign-off at the bottom if you want a different name.
- The “Love Story” link opens a Spotify search for Taylor Swift's original recording. It does not autoplay music.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `for-harinee`.
2. Upload the contents of this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then Save.
6. GitHub will show the published website URL in the Pages section.
